MRP (Material Requirements Planning) Dashboard
A modern Python/Streamlit web application designed to digitize and simplify the manufacturing process. It replaces scattered Excel files with a centralized, interactive dashboard, making production planning faster and error-free.

Key Features (What it does):

Smart Recipe Management: Easily edit production recipes. The app automatically calculates how many kilograms of each raw material are needed for the whole year.

Live Analytics: Visualizes the most used materials and top recipes using clear, horizontal bar charts.

Bulk Updating: If a raw material is discontinued, users can find and replace it across all recipes with a single click.

Recycling Tracker: Compares how much recycled material is produced versus how much is needed, ensuring the factory never runs out of stock.

Virtual Lab (Quality Prediction): Allows users to test new recipes digitally. It mathematically predicts if the final product will be strong enough, saving physical materials and lab testing time.
